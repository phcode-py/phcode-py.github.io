# Philipp Reinhardt

A personal website in a single HTML file, with inline CSS and no JavaScript or build step.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8765` in this directory.

## Publishing

Intended repository: `phcode-py/phcode-py.github.io`.
Configure GitHub Pages to deploy from the repository's root directory.

Edit `index.html` to update the page. The public project descriptions come from the corresponding GitHub repositories.
