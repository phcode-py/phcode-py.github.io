# Philipp Reinhardt

A personal website in a single HTML file, with no CSS, JavaScript, or build step.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8765` in this directory.

## Publishing

Repository: `phcode-py/phcode-py.github.io`.
GitHub Pages deploys from the root directory of `main`.

Edit `index.html` to update the page. The public project descriptions come from the corresponding GitHub repositories.
